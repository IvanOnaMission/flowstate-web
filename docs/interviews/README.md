Each file is `<slug>-answers.md`, created by `/seo-interview docs/briefs/<slug>.md`. Johan runs the command on a call with Ivan and types Ivan's answers word for word. Ivan doesn't use Claude Code.

Rules:
- Answers are never edited after the call. A correction is a new dated line under the answer, in Ivan's words.
- A line may be published only if it has a "yes" under Read-back, and it still follows D06 (no prices or percentages), except that a blog post may show the figures D45 allows, each listed in the post's `figures` with a sourced `claims` line; never Flow State's own prices or results.
- When a page uses a line, cite it as `docs/interviews/<file>, Q<n>`. A claim about clients, numbers or results also needs a row in `decisions.md` before it goes live (`AGENTS.md`).
- No passwords, email addresses or clients' personal details. The command replaces them with `[removed]`.
